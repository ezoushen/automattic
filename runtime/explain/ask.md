# Ask with context

Every question to the user, and every decision listed for them, brings its context
first, because the user may have lost it while the work ran. Apply the re-pitch steps
before asking, without waiting to be told they are lost: start at the first fact they
may not know, state an earlier decision by its content and where it came from, define
an internal name where it first appears, and never a ticket or decision ID in place of
what it means. The user should be able to answer without asking what the question
refers to.

The re-pitch steps are in [explain](explain.md#re-pitch-what-lost-the-reader).
