# Grilling never asks the user about implementation detail

Interviews ask the user only about principles and material forks: goals, what may change or must
keep working, behavior they would notice, cost or resource limits, irreversible actions and choices
they reserved, even at exhaustive depth; the agent decides implementation detail within those
answers and shows the material choices for veto. We chose this over Matt Pocock's whole-frontier
rounds, which also asked implementation detail and once put six detailed questions to the user at
once, more than they could answer from their priorities.
