# Grilling never asks the user about implementation detail

Interviews ask the user only about goals, principles, what may change or must keep working, and
behavior they would notice, even at exhaustive depth; the agent decides implementation detail within
those answers and shows the material choices for veto. We chose this over Matt Pocock's
whole-frontier rounds, which also asked implementation detail and put six questions to the user at
once in the stl10n work.
