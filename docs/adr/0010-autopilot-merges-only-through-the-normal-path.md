# Autopilot merges only through the repository's normal path

Autopilot ends once the PR is open and its required checks pass, and merges only when the user adds `--auto-merge`. Even then it merges only after the required checks and the repository's approval path are satisfied, never by an admin override or by approving its own PR; a missing approval ends the run waiting on the user. We chose this over letting a hands-off run merge on its own judgment, because the user chose to keep the merge decision unless they grant it, and an author may not satisfy their own independent-review requirement.
