# ADRs are superseded, never rewritten

A changed decision is a new ADR that names the one it supersedes; the old ADR's status line is its
only edit, apart from repairing a broken status or supersede link, and a partial overrule supersedes the whole ADR and restates what still holds. We chose
the immutable log most sources use over editing ADRs in place, because it keeps the order in which
decisions were made, and over an "amends" status, because a decision split across two records is
easy to misread.
